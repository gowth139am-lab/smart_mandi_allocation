## Reported manual test evidence

- **Admin Sales Reports:** Sale ID 1; Buyer Amit Wholesale; 50 kg; INR 500; status `PENDING`; payment `UNPAID`. The report displayed one sale, INR 500 total, 50 kg of Tomato, one November 2026 sale, and the Dharwad Demo Market breakdown. The monthly recursive timeline showed zero-sales months.
- **MongoDB:** A disposable Tomato quality observation was created and retrieved through the Farmer Quality Observations interface, its measurement was edited, and the disposable observation was deleted.
- **PostgreSQL RBAC:** The provisioning script was executed only against `smart_mandi_test_market_prices`. `smart_mandi_report_reader` was verified as `NOLOGIN`, without superuser, database-creation, or role-creation privileges. SELECT grants were verified on exactly seven specified tables/views. `has_table_privilege()` returned SELECT=true and INSERT/UPDATE/DELETE=false for `public.sales`. No restricted-role SQL session was tested.

These results are recorded from the supplied test evidence; this documentation update did not connect to PostgreSQL or MongoDB or rerun those tests. Never use the protected `smart_mandi_db` for demonstrations.
